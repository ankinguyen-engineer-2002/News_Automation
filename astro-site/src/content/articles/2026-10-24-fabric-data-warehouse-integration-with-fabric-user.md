Microsoft Fabric Data Warehouse now integrates with Fabric User Data Functions in preview, so you can extend T-SQL with custom Python logic without building separate applications or pipelines. Use the integration to send email or Teams messages, retrieve parameters and secrets from Fabric variable libraries or Azure Key Vault, and access data across OneLake. These capabilities are now available directly from T-SQL queries in your Warehouse. Figure: Calling a Fabric User Data Function from a T-SQ
